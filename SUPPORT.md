# Support

For Apple Notes for Codex, open a GitHub issue in this repository. Include:

- macOS version, Codex client, and plugin version.
- The tool or operation that failed.
- A redacted error message and steps to reproduce with sample text.

Issues are public. Do not include private notes, passwords, API keys, account identifiers, or unredacted screenshots. Before reporting an access failure, check **System Settings → Privacy & Security → Automation** for permission to control Notes.
