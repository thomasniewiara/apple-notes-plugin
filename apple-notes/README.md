# Apple Notes plugin

A local macOS plugin by Thomas Niewiara. Free under the MIT License.

This directory is the complete plugin package. See the repository README for installation, tool descriptions, privacy information, and support.

Requires Apple Notes, Python 3, and macOS Notes Automation permission. Locked notes cannot be read. Notes with attachments cannot be updated. Replacement removes body formatting. Read before editing and pass the modification token.

The repository is a GitHub-hosted plugin marketplace. It has not been approved for OpenAI’s public Plugins Directory.
